# 保存与分享实验

实验文件保存 Python 代码、环境版本记录和观察位置。接收方可以先检查代码，再运行并恢复到相应的步骤、变量和切片，继续分析。

实验文件不包含张量数值快照、Python 环境或外部数据文件。分享不会创建公共实验库，也没有账号、访问控制或远程撤销功能。

## 分享链接

1. 运行代码，选定执行步骤、变量和切片；需要时设置对照基准。
2. 点击顶部“分享”，在“分享实验”对话框中复制链接。
3. 接收方打开链接后，TensorV 新建一个脚本副本供检查，不覆盖已有脚本，也不自动执行。
4. 接收方确认代码后点击“运行”，TensorV 根据新生成的执行结果恢复观察位置。

链接的 `#tv=...` 部分直接携带实验内容，不是服务器数据库中的实验编号。浏览器加载页面时不会把 URL fragment 作为 HTTP 请求的一部分发送给服务器；点击运行后，代码才按当前工作区的执行方式提交到 Python 环境。

网页版使用当前站点地址生成链接。本地 `localhost` / `127.0.0.1` 地址通常只有你自己的计算机可以访问，发给其他人时可改用实验文件。VS Code 生成的分享链接指向公共 TensorV 网页；接收方在那里点击运行时，使用的是公共执行环境，不是发送方的本机 Python。

链接没有加密。任何持有完整链接的人都能读取代码，复制链接还可能将其保存在聊天记录、剪贴板或浏览器历史中。不要分享含密钥、密码或机密数据的代码。删除本地脚本不会撤销别人保存的链接。

## 实验文件

在“分享实验”中点击“下载实验文件”，将 `.tensorv.json` 发送给接收方。接收方点击侧栏的“打开实验”，检查导入的副本内容后再运行。链接较长、传输工具可能截断地址或需要长期归档时，优先使用文件。

VS Code 中可使用 **TensorV: 打开实验文件** 命令选择 `.tensorv.json`；实验导出通过 VS Code 原生保存对话框完成。打开实验文件同样只进入预览。它不映射到原 Python 文件，也不提供“返回源码”定位；详见 [VS Code 插件](vscode.md)。

实验导入会新建副本。关闭浏览器页面前，已有副本可由浏览器本地存储保存；需要独立备份时仍应导出文件。VS Code 的面板副本不是项目文件，应通过保存对话框写入文件后再关闭面板。

## 保存的内容

| 内容 | 范围 |
| --- | --- |
| Python 代码与标题 | 单个脚本的当前文本和实验标题 |
| 环境记录 | TensorV 版本与已知的 PyTorch 版本；PyTorch 版本尚未知时为空 |
| 当前步骤 | 步骤序号、源代码行号及语句 |
| 对照基准 | 固定基准步骤，或默认的上一步 |
| 两侧张量视图 | 变量名、原 shape、行列维度、固定索引、当前分页起点 |
| 显示设置 | 前后对照、热力图、数值精度、画布 / 存储映射 / 统计标签 |

不包含服务端快照 ID、实际张量数据、标准输出、异常记录、其他脚本、撤销历史或运行中的 Python 变量。也不会额外保存解释器路径或源文件 URI；如果代码本身含有路径、注释或其他信息，这些文本仍会随代码一起分享。

`.tensorv.json` 与切片数据导出的 `.json` 含义不同：实验文件用于重新执行代码并恢复观察设置；切片 JSON / CSV 用于保存当时可见页的数值。

## 预览与恢复

打开链接或导入文件后，实验处于待运行状态。正常编辑、切换脚本或刷新页面都不会代替首次运行确认。应先阅读代码，再点击“运行”；主动开启自动运行也表示允许执行该副本。

恢复使用本次运行生成的新张量快照，不复用发送方的快照 ID。代码或环境变化可能导致步骤、变量、shape 或可用数值不同；不能匹配时，界面会提示并回退到有效的默认视图，不能保证与发送方完全一致。

环境记录用于对照，不会自动安装依赖、切换解释器或下载文件。包版本、设备、随机源、外部数据与代码副作用都不由实验文件封装。即使代码相同，也不保证计算结果完全一致。

浏览器公共实例在服务器沙箱中执行；本地网页版和 VS Code 使用相应机器上的可信 Python，具有该用户的文件和网络权限。分享不会改变执行环境的权限边界，只运行你信任的代码。

## 格式与限制

当前文件格式为 `format: "tensorv-experiment"`、`version: 1`。应用版本为 0.4.0，文件格式版本与应用版本是不同字段。文件使用 UTF-8 JSON，限制为 128 KiB，代码最多 20,000 个字符；完整分享地址最多 16,384 个字符。

链接采用 gzip 加 base64url，压缩没有收益或不受支持时使用未经压缩的 UTF-8 JSON 编码。接收方浏览器不能解压时，可更新浏览器或改用实验文件。编码和压缩都不提供保密性。

导入会检查格式版本、字段类型、维度及索引范围。损坏、被截断、超过大小限制或来自不兼容格式版本的数据会被拒绝，不会尝试执行其中的代码。实验文件不是任意 JSON 文件，切片导出文件不能作为实验导入。
