# 用户指南

本文介绍当前源码版本的功能。线上演示可能仍运行较早版本；VS Code 的安装、解释器和文件副本语义见 [VS Code 插件](vscode.md)。

## 工作区与脚本

侧栏用于选择脚本、打开示例和访问命令搜索。编辑器位于主工作区左侧，检查器位于右侧；可拖动分隔线调整宽度，也可收起侧栏或启用专注画布。窄屏设备通过“编辑器 / 检查器”切换视图。主题开关位于侧栏底部。

点击“新建脚本”创建文件，点击顶部文件名进行重命名。打开示例或导入 Python 文件会创建独立脚本，不覆盖当前内容。每个浏览器工作区最多保存 20 个脚本，每个脚本最多 20,000 字符。

脚本内容自动写入当前浏览器的 localStorage。切换脚本时保留各自的编辑和撤销历史；刷新页面后只恢复代码，不恢复撤销历史。隐私模式、禁用站点存储或清除站点数据可能使内容丢失。下载为 `.py` 文件后才有独立于浏览器的副本。

运行时，代码会被提交到当前连接的执行服务。使用公开服务时，不要在代码、输出或张量中放入密码、密钥和机密数据。

## 执行和回看

点击“运行”或按 `Ctrl / ⌘ + Enter` 执行当前脚本。开启自动运行时，停止编辑约 650 ms 后触发执行。处理尚未完成的代码或较慢任务时，可以关闭自动运行。

每次执行都从头运行代码，并重置 PyTorch 随机种子为 0。代码不是交互式 REPL：前一次执行中的 Python 变量不会作为下一次执行的变量环境继续使用。

检查器在顶层语句执行完成后记录张量状态。选择执行步骤查看该时刻的变量，也可将编辑器光标移到已执行语句以选择对应步骤。上一条、下一条和播放控件仅浏览已生成的快照，不会重新执行代码。

开启前后对照后，可从对照基准下拉框选择同次执行中的其他步骤。手动选择的观察变量会在后续步骤仍存在时继续保持选中；不存在时回退到该步骤可用的 Tensor。不同次执行之间不能比较存储编号。

函数和循环可以执行，但检查器不逐次记录函数内部语句或每轮循环。列表、元组和字典中的 Tensor 按变量路径展开；直接求值的 Tensor 表达式显示为“结果”。

标准输出和标准错误显示在编辑器下方的“输出”区域。异常包含错误类型和位置；已完成步骤可用于回查失败前的状态。代码尚未写完时，界面可以保留上一次成功结果，应结合运行状态判断结果是否对应当前代码。

## 形状诊断

对于可识别的广播、矩阵乘法、`reshape` 和 `view` 错误，错误区域会列出实际输入 shape、标出冲突维度，并给出修改建议。广播按右侧对齐维度；重塑错误会列出目标 shape，区分元素总数、`-1` 推断和空张量歧义；非连续 Tensor 的 `view` 会提示 stride 要求。

诊断基于实际执行错误和输入形状，不会自动修改代码，原始 PyTorch 错误仍保留。当前覆盖顶层简单变量操作与可直接读取的整数 shape；复杂表达式、索引、Tensor 子类、`out` 参数、计算得到的 shape 和同一行多条语句可能只显示原始错误。

## 张量画布

选择 Tensor 后，为画布指定行维度、列维度，并通过索引控件固定其余维度。每页最多显示 24 行、24 列，大尺寸维度通过分页浏览。

悬停元素查看完整坐标，点击可锁定选中元素，按 `Esc` 解锁。开启前后对照后可查看语句输入和输出；形状相同时，同坐标发生数值变化的元素以橙色边框标识。

热力图按可用完整快照的最小值、最大值着色。显示精度可设为 4、6 或 8 位有效数字，只影响界面格式，不修改数据或导出值。

## 存储与布局

属性区域显示 shape、dtype、stride、storage offset、连续性和存储编号。存储映射展示当前可见切片的坐标与存储位置。

- 相同存储编号表示本次执行中共享同一底层存储。
- 存储偏移以元素为单位，计算方式为 `storage_offset + Σ(index[i] × stride[i])`。
- 选中元素时，相同存储编号且 dtype 相同的元素会联动高亮；重叠视图中可能有多个坐标对应同一位置。
- 逻辑数据大小为 `numel × element_size`，不等于该操作新增分配的内存。

历史数值通过独立副本保存，后续原地修改不会重写此前快照。存储编号描述原始 Tensor 之间的共享关系，不表示这些快照副本互相共享内存，也不能跨执行比较。

## 统计和导出

数值统计中的最小值、最大值、均值和总体标准差基于完整可用快照，仅统计有限实数；NaN 和 Inf 单独计数。复数不提供实数统计。直方图基于当前可见切片，两者的统计范围不同。

超过 JavaScript 安全整数范围的整数以十进制字符串保留完整值；这些值不会参与前端热力图和直方图的数值分桶。后端统计使用 float64，对大整数为近似计算。

导出按钮支持以下格式：

| 格式 | 内容 |
| --- | --- |
| CSV | 当前页逐元素坐标、原始数值和存储偏移 |
| JSON | 当前页数值、坐标、偏移以及 shape、stride 和切片信息 |

导出对象是**操作后画布的当前页**，最多 24 × 24 个元素，并非整个 Tensor 或整次运行。需要检查其他部分时，应先切换切片或页码。

## 使用限制

普通稠密 Tensor 支持数值浏览；稀疏 Tensor 和 meta Tensor 只显示元数据。单个 Tensor 超过 100,000 个元素，或历史数值预算耗尽时，数值快照不可用。本地模式的历史数值预算为 64 MiB；公共模式为 2 MiB，且所有历史数值合计不超过 100,000 个元素。此时应在代码中先取较小切片，再运行。

执行快照是临时状态。重新执行、服务重启或公共服务会话过期后，需要再次运行才能查询切片。浏览器保存的脚本文件与服务器上的执行快照是两类独立数据。

公共服务使用匿名浏览器会话，不提供账号或跨设备同步。同一浏览器的多个标签页共享会话：在一个标签页重新运行代码后，另一个标签页的旧快照可能过期。空闲超时或容量不足时，服务也可能回收会话，需要重新运行代码。公共服务还限制执行频率和并发；收到资源繁忙或频率限制提示时，稍后手动重试。
