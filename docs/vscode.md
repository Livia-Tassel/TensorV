# VS Code 插件

TensorV 在 VS Code 中运行 Python 文件或选区，将执行结果显示为张量快照。运行整个文件后，检查器与该文件建立源码联动，后续修改可直接更新检查结果。它使用你选择的 Python 环境，自动管理执行子进程；不需要打开终端启动 TensorV 服务，也不需要填写服务器地址。

## 安装 VSIX

需要 VS Code 1.90+，以及安装了 `torch`、`numpy` 的 Python 3.10+ 环境。VSIX 包含界面和 TensorV 的 Python 源码，不包含 Python 或 PyTorch。日常使用无需 Node.js。

当前插件尚未发布到 Marketplace。获取本地构建的 `tensorv-0.4.1.vsix`，或从对应成功的 GitHub Actions 运行页面下载 VSIX 产物并解压，然后：

1. 在 VS Code 的“扩展”视图点击 `…`。
2. 选择“从 VSIX 安装”，打开 `.vsix` 文件。
3. 按 VS Code 提示重新加载窗口。

也可以通过终端安装：

```sh
code --install-extension path/to/tensorv-0.4.1.vsix
```

从源码构建时，先在仓库根目录安装前端依赖，再运行：

```sh
npm ci
npm ci --prefix extensions/vscode
npm run package:vscode
```

产物为 `extensions/vscode/tensorv-0.4.1.vsix`。构建命令不会发布到 Marketplace，也不会更新线上演示实例。

## 选择 Python

打开并信任你的 Python 项目。TensorV 按以下顺序选择解释器：

1. `tensorv.pythonPath` 指定的可执行文件。
2. 当前工作区的 `.venv`。
3. 已安装 Microsoft Python 扩展时，该扩展选择的解释器。
4. 扩展宿主 PATH 中的 `python`。

命令面板中的 **TensorV: 选择 Python 解释器** 支持输入路径、浏览可执行文件及恢复自动选择。不要求安装 Microsoft Python 扩展。

也可在工作区设置中指定路径，例如 Windows：

```json
{
  "tensorv.pythonPath": "${workspaceFolder}/.venv/Scripts/python.exe"
}
```

macOS / Linux 可使用 `${workspaceFolder}/.venv/bin/python`。设置填写可执行文件路径，不附加命令参数。缺少依赖时，在目标解释器对应的终端中运行 `python -m pip install torch numpy`，或选择已经安装依赖的环境；插件不会自动安装软件。

SSH、WSL 和 Dev Containers 中，插件在相应的远程扩展宿主执行，Python 路径和文件权限也属于该环境。

## 运行文件或选区

打开 `.py` 文件后，使用编辑器标题栏按钮、右键菜单或命令面板：

| 命令 | 行为 |
| --- | --- |
| TensorV: 运行当前 Python 文件 | 执行当前全文，包括尚未保存的修改，并与该文件建立源码联动 |
| TensorV: 运行所选 Python 代码 | 仅执行选中的原始文本，作为独立副本检查 |
| TensorV: 打开张量检查器 | 打开面板，不自动执行代码 |
| TensorV: 打开实验文件 | 选择 `.tensorv.json`，创建待运行的实验副本 |
| TensorV: 选择 Python 解释器 | 更换执行环境，下次运行生效 |
| TensorV: 重启执行环境 | 关闭现有执行进程，清除快照 |

### 文件源码联动

首次使用“运行当前 Python 文件”执行后，检查器顶部显示“源码联动”及“已更新 / 待更新”等状态。继续在 VS Code 的 Python 编辑器中修改同一文件，包含未保存的内容，修改会同步到检查器的只读代码镜像；无需保存文件或重复使用标题栏命令。

“自动运行”首次使用默认关闭，之后保留开关偏好。开启时，停止编辑约 650 ms 后运行最新全文；关闭时只同步代码并标记结果待更新。点击检查器中的“运行”时，会读取绑定文件的最新内容，不使用旧副本。若关闭自动运行，先确认待更新状态再使用已有结果。

检查器默认显示执行结果。退出“专注画布”后可查看只读代码镜像；点击顶部“在源文件中编辑”可打开原文件，修改仍在 VS Code 原编辑器中进行。TensorV 不通过面板覆盖源文件。

仅切换到其他编辑器或修改其他文件，不会自动更换绑定目标。要检查另一个文件，在该文件中再次使用“运行当前 Python 文件”。

在检查器中切换到示例或普通脚本时，暂停此前文件的同步和自动执行；切回当前联动文件对应的脚本时，会重新读取最新内容。运行另一个文件或选区、导入实验或关闭检查器，会结束先前的文件绑定；保留下来的旧脚本作为独立副本。需要恢复联动时，从原文件再次使用“运行当前 Python 文件”。导入实验仍需手动运行。

关闭、删除或重命名源文件后，检查器会提示“源码不可用”，需要从有效文件重新运行以建立绑定。源码超过 20,000 字符时暂停运行，缩短后可继续。

### 选区和独立脚本

“运行所选 Python 代码”保留副本语义，不建立整文件联动，也不会因之后修改源文件而隐式执行整个文件。需要更新选区时，重新选择并运行。

选区应包含能独立运行的完整语句。它不会自动执行上文，也不继承终端、Notebook、调试器或上一次 TensorV 运行中的变量；原始缩进同样保留。例如，只选择 `y = x.transpose(0, 1)` 时，需要将定义 `x` 的语句一并选中。引擎预置了 `torch`，其他依赖仍需在代码中导入。

选区副本、示例及实验代码可在检查器中编辑。它们不是项目文件，需保留时使用下载按钮，在 VS Code 保存对话框中选择位置；关闭面板或重载窗口前应保存重要修改。CSV / JSON 导出也通过同一保存对话框完成。

“返回源码”定位执行步骤对应的原文件行，选区会加上原始起始行偏移。联动文件修改后，旧结果被标记为待更新，此入口暂时隐藏；重新执行后恢复。编辑文件可使用顶部“在源文件中编辑”。选区副本被修改或源文件版本变化后，应重新运行对应选区再定位。

## 实验导入与分享

使用 **TensorV: 打开实验文件**，或检查器侧栏中的“打开实验”，选择 UTF-8 编码的 `.tensorv.json`。打开实验只显示新的脚本副本，不自动执行；检查代码后点击“运行”，再根据当前执行结果恢复保存的观察位置。

实验文件没有源文件映射，因此导入实验后不提供原 Python 文件的“返回源码”定位。环境版本记录不会替你选择解释器或安装依赖。

在“分享实验”中可复制分享链接，或通过原生保存对话框导出 `.tensorv.json`。复制链接由 VS Code 写入系统剪贴板，链接指向公共 TensorV 网页；接收方点击运行后使用公共环境，不继承你的本机环境。需要在其他本机环境继续分析时，可传递实验文件。文件最多 128 KiB，只包含单个脚本和观察设置，不包含实际张量快照；完整语义见[保存与分享实验](experiments.md)。

## 检查结果

可选择执行步骤和 Tensor，调整切片维度、查看存储映射与统计，并选择同次运行中的其他步骤作为对照基准。支持的形状错误会显示输入形状、冲突维度及建议，原始 Python 错误仍保留。详细数据语义见[用户指南](user-guide.md)。

TensorV 记录顶层语句执行后的张量状态。它不是断点调试器，不读取正在调试的进程变量，也不逐次跟踪函数内部语句或循环迭代。

## 权限和限制

Python 在扩展宿主所在机器上执行，拥有当前用户的文件、网络及其他解释器权限。执行进程用于超时恢复，**不是安全沙箱**；只运行你信任的代码。不受信任的工作区可以打开检查器，但执行命令和 Webview 执行请求都会被拒绝。

插件本身不启动 HTTP 端口，也不将代码提交到 TensorV 公共实例。用户运行的 Python 代码仍可按自身逻辑访问网络。

每个脚本最多 20,000 字符，单次执行默认限制为 8 秒。最多记录 128 步，每步最多 32 个 Tensor；单个 Tensor 数值上限为 100,000 个元素，历史数值预算为 64 MiB，每页最多显示 24 × 24 个元素。重启执行环境或关闭面板会释放执行进程，旧快照需要重新运行后生成。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 无法启动 Python | 使用“选择 Python 解释器”，确认路径指向可执行文件；在“输出”面板选择 TensorV 查看记录 |
| 缺少 PyTorch / NumPy | 在所选解释器环境安装依赖；确认终端的 `python` 和插件所选路径一致 |
| 选区出现 `NameError` / `IndentationError` | 补全依赖定义并选择完整顶层语句；选区不会自动补上下文或去除缩进 |
| 执行超时或快照过期 | 缩短代码、减小张量，然后重新运行；必要时使用“重启执行环境” |
| 修改源码后结果未变化 | 确认当前脚本顶部显示“源码联动”；关闭自动运行时，点击检查器“运行”更新结果。旧副本需从源文件重新运行以恢复绑定 |
| 检查器内代码无法编辑 | 当前脚本是绑定文件的只读镜像，请在 VS Code 的原 Python 编辑器中修改 |
| 显示“源码不可用” | 检查文件是否已关闭、删除或重命名；打开有效文件后重新使用“运行当前 Python 文件” |
| 返回源码提示文件已修改 | 联动文件重新运行最新全文；选区重新选择并运行，更新行号与版本记录 |
| 面板打开但无法执行 | 确认工作区已受信任，并检查解释器及其依赖 |
